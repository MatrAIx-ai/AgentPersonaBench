# Instruction

Shop the **Nestwell** page and order what you would genuinely buy. Nothing is
compulsory: a category may hold any number of products or none, the optional
extras are yours to take or leave, and **Place order** finishes the visit.

## Files (container runs)

- Site: `/app/input/site/index.html`
- The ordered page state is recorded at `/app/output/anchor/order.json`:

```json
{ "orderedItemIds": ["<id>", "<id>", "<id>"] }
```

Use exact element ids from the page. Just do the shopping — no explanation.
