# Restock your household in the HomeStock app

The **HomeStock** shopping app is already open on screen. Use it to restock a
few household essentials.

1. Browse the catalog — every product is on screen at once; read what each one is.
2. Tap the **+ Add** button on **3–4 products** you would genuinely buy to add
   them to your cart.
3. When you're happy with your cart, tap **Place order**.

Buy the products *you* would actually choose, as this person. The task does not
tell you which specific products to pick — decide based on what each product is.
You're done once the order is placed (the app confirms with "Order placed"). You
do not need to write any files; placing the order records it.
