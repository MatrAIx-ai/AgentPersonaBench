# Apply for a home-safety visit in the Bramblewood Home Safety Scheme app

The **Bramblewood Home Safety Scheme** app is already open on screen. Use it to apply for the council's free home-safety visit and set up the kit and the visit arrangements for your own home.

1. Read every option in each of the five sections (smoke alarm, doorbell, how the fitter confirms your slot, kit instructions, yearly visit reminder); each card says what that option involves.
2. Click **Select** on the one option in each section that you would genuinely go with.
3. Once every section shows a selection, click **Submit application**. You are done when the confirmation screen appears.

The app records the result itself, in `/app/output/safety_kit.json`; do not create or edit that file yourself.
