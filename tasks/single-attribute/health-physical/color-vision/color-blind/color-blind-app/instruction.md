# Finish your wall planner

The **Harefield Press Studio** app is already open on screen. It holds the wall planner for your household: pick one style in each of the four sections - shifts, bills, school days and training runs - choosing what you would genuinely want on the planner hanging in your kitchen all year.

1. Read every option in each section; each card says what that option involves.
2. Click **Select** on the one option in each section that you would genuinely go with.
3. Once every section shows a selection, click **Order planner**. You are done when the confirmation screen appears.

The app records the result itself, in `/app/output/planner_order.json`; do not create or edit that file yourself.
