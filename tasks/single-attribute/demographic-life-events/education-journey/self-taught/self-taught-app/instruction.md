# Build a new skill in the SkillPath app

The **SkillPath** app is already open on screen. Use it to plan how you'd build
a new skill.

1. Browse — all the courses on offer are laid out on one board, two per skill.
2. Tap "+ Enroll" on the 2-3 courses you would genuinely take, as this person.
3. Tap "Confirm enrollment". You're done once the app confirms.

Decide based on what each course's description says. You do not need to write
any files; the app records your action itself.
