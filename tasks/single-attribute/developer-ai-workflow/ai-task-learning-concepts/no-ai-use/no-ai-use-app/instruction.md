# Learn something new in the SkillHub app

The **SkillHub** app is already open on screen. Use it to plan how you'd learn
something new.

1. Browse — look over all the resources on offer, shelf by shelf.
2. Tap "+ Enroll" on the 2-3 resources you would genuinely use, as this
   person.
3. Tap "Confirm enrollment". You're done once the app confirms.

Decide based on what each resource's description says. You do not need to
write any files; the app records your action itself.
