# Book Friday's trip to Kambele

Use the Wayfinder site to book your trip to Kambele for Adaeze's graduation next
Friday at 14:00. Kambele is about 180 km from Kessaro. Choose how you travel
there on Friday, how you get about in Kambele, and how you travel back on
Saturday, then confirm the booking. The booking is for you alone. You are done
when the confirmation reference appears.

The site records the booking and the interaction history in
`/app/output/anchor/booking_result.json`; do not create or edit that file
yourself.
