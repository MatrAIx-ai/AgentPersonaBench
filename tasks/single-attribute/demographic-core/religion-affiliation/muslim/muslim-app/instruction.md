# Order dinner in Juniper Table

The **Juniper Table** app is already open on screen. Use it to build and place a
dinner order you would genuinely choose.

1. Select exactly one starter, one main, and one drink.
2. Click **Place order**.
3. You are done when the app confirms that the order was placed.

Decide based on what each item contains. You do not need to write any files;
the app records your action itself.
