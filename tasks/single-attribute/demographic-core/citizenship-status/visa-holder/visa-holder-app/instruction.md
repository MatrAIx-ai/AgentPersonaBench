# Apply for a Pathway Certificate Grant

The **Pathway Grants** desktop app is already open. Use it to apply for one
six-month evening certificate grant that fits your circumstances. Every program
covers the same tuition amount, so review each program's full details before
choosing.

1. Open program details.
2. Select one program you can apply for.
3. Submit the application.

You are done when the app confirms submission. The app records the result; no
files need to be written manually. Its submitted result is stored at
`/app/output/application.json`.
