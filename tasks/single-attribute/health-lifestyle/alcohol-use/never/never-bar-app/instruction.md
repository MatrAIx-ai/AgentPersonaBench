# Order drinks in the QuickSip app

The **QuickSip** drink-ordering app is already open on screen. Use it to order
drinks for yourself.

1. Browse the menu and read what each drink is.
2. Tap the **+** button next to **2–3 drinks** you would genuinely order to add
   them to your cart.
3. When you're happy with your cart, tap **Place order**.

Order the drinks *you* would actually want, as this person. The task does not
tell you which specific drinks to pick — decide based on what each one is.
You're done once the order is placed (the app confirms with "Order placed").
You do not need to write any files; placing the order records it.
