# Instruction

The **CanteenOrder** app (Cafe Tamarind's order-ahead kiosk) is already open on
screen. Use it to order dinner for yourself.

1. Browse the menu — open each section tab (Mains, Sides, Drinks, Desserts) to see every item.
2. Click to add **one main, one drink, and anything else you fancy** — dishes
   you would genuinely order.
3. Click **Place order**. You're done once the app confirms.

Decide based on what each item is. You do not need to write any files; the app
records your order itself.
