# Order dinner for pickup

Use the Copper Kettle Kitchen website to order tonight's dinner for yourself: one main,
then the side, drink and sweet steps the site asks for.

Go through each step, choose what you would genuinely eat and drink, review your
choices, and place the order. You are done when the confirmation screen appears.

The site records your confirmed order and interaction history in
`/app/output/anchor/order_result.json`; do not create or edit that file yourself.
