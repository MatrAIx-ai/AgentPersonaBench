# Build next week's lunch box

The **Copper Kettle Weekday Box** app is already open on screen. Use it to build next week's lunch box for yourself: choose a Monday, Wednesday and Friday lunch, a snack, and whether to keep the bakery roll, then review and confirm the box. Choose what you would genuinely eat. You are done when the confirmation appears.

The app records the result itself, in `/app/output/box_order.json`; do not create or edit that file yourself.
