# Choose your next studio moves

The **CanvasDesk** app is already open on screen. Every card applies to the same in-progress canvas, uses available supplies, and has no deadline.

1. Browse the options — all eight studio cards are on screen; read what each one is.
2. Tap the **+** button next to exactly **3 options** you would genuinely use next (tapping
   again removes one you didn't mean).
3. When you're happy with your picks, tap **Set Plan**.

Decide from what each option is, as this person — the task does not tell you
which to pick. You're done once the app confirms with "Studio plan saved".
You do not need to write any files; submitting in the app records it.
