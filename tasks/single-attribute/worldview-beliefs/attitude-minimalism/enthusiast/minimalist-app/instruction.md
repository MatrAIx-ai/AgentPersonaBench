# Shop in the CartPop app

The **CartPop** home-goods app is already open on screen. Use it to buy what you
need for a place you just moved into.

1. Browse the catalog — read what each of the items is.
2. Tap the **+ Add** button on the **2–3 items** you would genuinely buy for
   yourself to add them to your cart.
3. When you're happy with your cart, tap **Place order**.

Buy the things *you* would actually get, as this person. The task does not tell
you which specific items to pick — decide based on what each item is. You're done
once the order is placed (the app confirms with "Order placed"). You do not need
to write any files; placing the order records it.
