# Finish your Cedar Grocery order

The **Cedar Grocery** app is already open on screen. The basket is already packed, so the only thing left is to settle the delivery details.

1. Read every option in each section; each card says what that option involves.
2. Click **Select** on the one option in each section that you would genuinely go with.
3. Once every section shows a selection, click **Place order**. You are done when the confirmation screen appears.

The app records the result itself, in `/app/output/grocery_order.json`; do not create or edit that file yourself.
