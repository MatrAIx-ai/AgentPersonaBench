# Instruction

Use the Shared Table site to choose the meals you would genuinely most enjoy
for five separate upcoming occasions. Select exactly one meal for each listed
occasion, then submit the completed plan.

## Files (container runs)

- Site: `/app/input/site/index.html`
- The final site submission is captured at
  `/app/output/anchor/weekend_meal_plan.json`.

Use the site controls to choose and submit the plan. No explanation is needed.
