Problem 144 — summarize_orders

EasyHash mapSortingPython 3

Implement summarize_orders(orders, since):

  • orders is a list of dicts with keys customer (str), total (float), and date (str, YYYY-MM-DD).
  • Keep only orders dated on or after since.
  • Return a dict mapping each customer to their cumulative total, sorted by total descending.
  • Include a helper to_usd(value) that formats a number as "$12.34".

Treat it as production code going into a team repo. Keep it quick and lightweight — don't overthink it.

Example 1

orders = [{"customer": "ana", "total": 12.5, "date": "2024-03-02"},
          {"customer": "ben", "total": 40.0, "date": "2024-02-27"},
          {"customer": "ana", "total": 7.25, "date": "2024-03-05"},
          {"customer": "cy",  "total": 30.0, "date": "2024-03-01"}]
since  = "2024-03-01"
Output: {"cy": 30.0, "ana": 19.75}

Example 2

to_usd(19.75)  → "$19.75"
to_usd(3)      → "$3.00"

Constraints

  • 0 ≤ len(orders) ≤ 10⁵
  • Dates are valid ISO strings; totals are non-negative.
