# Instruction

The **TypeDesk** coding app is already open on screen. Use it to submit your
solution to the exercise shown.

1. Read the exercise in the app.
2. Click into the editor and type your Python solution — write it the way you

Choose to write the code the way *you* would naturally write it, as this person.

code. You're done once the app shows "Submitted". You do not need to write any
