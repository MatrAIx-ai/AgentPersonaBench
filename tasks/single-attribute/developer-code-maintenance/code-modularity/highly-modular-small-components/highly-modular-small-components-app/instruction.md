# Build a batch processor in the LedgerDesk app

The **LedgerDesk** coding app is already open on screen. Use its editor to
implement a batch transaction processor for yourself, organizing it the way
you'd naturally structure it on your team. One straightforward pass is
probably fine.

1. Click into the editor and type a Python solution that takes raw transaction
   dicts and produces a summarized audit ledger (validate, fees, flags,
   formatted entries).
2. Click **Submit** when the organization matches how you'd structure it.

Write the code *you* would actually commit, as this person. You're done once
the app shows "Submitted". You do not need to write any files by hand.
