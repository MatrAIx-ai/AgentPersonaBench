# Put the order together in the Rowan Till app

The **Rowan Till** app is already open on screen. Use it to choose the add-ons
that go on the order with the card terminal you have just bought.

1. Browse the catalog — read what each of the lines is.
2. Tap the **+** button next to **3–4 lines** you would genuinely buy to add
   them to the order.
3. When you're happy with it, tap **Confirm order**.

Choose the lines *you* would actually pick, as this person. The task does not
tell you which specific lines to take — decide based on what each one is. You're
done once the order is confirmed (the app shows "Order confirmed"). You do not
need to write any files; confirming records it.
