# Choose upcoming activities

Use the **Harborlight Activity Board** website to choose one option for each
of five separate upcoming occasions. Review all five, make the choices you
would genuinely prefer, and confirm them.

## Files (container runs)

- Site: `/app/input/site/index.html`
- The live page writes the confirmed DOM submission to
  `/app/output/anchor/weekend-plan.json`.

Do not create that file directly. Complete and confirm the plan through the
website.
