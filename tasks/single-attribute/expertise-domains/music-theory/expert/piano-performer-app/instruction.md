# Plan three practice hours

The **ScoreRoom** app is already open on screen. Every card is a free 60-minute session in the same room on the same piano.

1. Browse the options — read what each one is.
2. Tap the **+** button next to exactly **3 options** you would genuinely use in your own preparation (tapping
   again removes one you didn't mean).
3. When you're happy with your picks, tap **Add to Plan**.

Decide from what each option is, as this person — the task does not tell you
which to pick. You're done once the app confirms with "Practice plan saved".
You do not need to write any files; submitting in the app records it.
