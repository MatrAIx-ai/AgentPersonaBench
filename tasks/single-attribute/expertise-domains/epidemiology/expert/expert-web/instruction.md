# Study Design Console

Use the provided console to complete each open study audit. For every study,
select an adjustment strategy, an estimand, and the strongest claim you would
genuinely approve, then submit the review.

## Files (container runs)

- Site: `/app/input/site/index.html`
- After real page interactions, the console records its confirmed submission at
  `/app/output/anchor/causal_console_review.json`.
