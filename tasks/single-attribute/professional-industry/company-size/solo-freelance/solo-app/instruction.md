# Set up your working software in the WorkStack app

The **WorkStack** app is already open on screen. Use it to put together the
software setup you run your work on.

1. Browse the catalog and read what each line is.
2. Tap **+ Add line** on **3–4 lines** you would genuinely buy to add them to
   your setup.
3. When you're happy with it, tap **Review setup**, then **Confirm setup**.

Choose the lines *you* would actually pick, as this person. The task does not
tell you which specific lines to take — decide based on what each one is. You're
done once the setup is confirmed (the app shows "Setup confirmed"). You do not
need to write any files; confirming records it.
