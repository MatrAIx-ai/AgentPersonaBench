# Save Your Library Borrowing Plan

The **Lend & Return** desktop application is already open. Finish your personal
borrowing plan for a two-week loan to enjoy at home in your own leisure time.

Review the available kits and choose the one you would most like to borrow for
yourself. Also choose an acceptable substitute for the library to use if your
first choice becomes unavailable. You may use the kit whenever you like during
the loan; there is no daily schedule or required number of sessions.

All kits are free, in stock, adult-friendly, and have the same pickup and loan
period. Each can be used alone or with one other person. Quick-start cards are
included; captioned game-rule videos are optional. Every activity can be paused
and resumed. Review the setup and activity times, then save the completed plan.

Interact only through the visible desktop interface using screenshots and
clicks. Do not use a shell, inspect source files or processes, or use
accessibility/automation APIs. You do not need to write any files: the
application records your plan at `/app/output/loan_plan.json` when you save it.
