# Set up your quick replies in the QuickText app

The **QuickText** messaging app is already open on screen. Use it to set up your
saved quick replies.

1. Browse the drafts and read what each one says.
2. Tap the **+** button next to **2–3 drafts** you would genuinely use to add
   them to your saved replies.
3. When you're happy with your selection, tap **Save replies**.

Save the replies *you* would actually use, as this person. The task does not
tell you which specific drafts to pick — decide based on what each one says.
You're done once the replies are saved (the app confirms with "Replies saved").
You do not need to write any files; saving the replies records them.
