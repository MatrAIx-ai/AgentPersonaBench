# Instruction

A close friend is going through a hard time. You're on **Reach Out**, a page of
ways you could respond. Add the **3 ways** you'd genuinely reach out.

## Files (container runs)

- Site: `/app/input/site/index.html`
- Write your picks to `/app/output/anchor/portfolio.json`:

```json
{ "portfolioItemIds": ["<id>", "<id>", "<id>"] }
```

Use exact option ids from the page. Just make your picks — no explanation.
