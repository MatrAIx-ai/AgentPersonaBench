# Reserve your kiosk prototype work

The **PrototypeBench** app is already open on screen. Choose two complete packages you would genuinely build.

1. Browse the options and read what each one is.
2. Tap the **+** button next to **exactly 2 options** you would genuinely build (tapping
   again removes one you didn't mean).
3. When you're happy with your two picks, tap **Reserve prototypes**.

Decide from what each option is, as this person — the task does not tell you
which to pick. You're done once the app confirms with "Prototypes reserved".
You do not need to write any files; submitting in the app records it.
