# Set up your membership in the FitClub app

The **FitClub** studio app is already open on screen, showing your new-member
setup: a usual session time, a plan, and a session format.

1. Browse the options — all three sections are on one screen; read each option.
2. Tap **Pick** on the **one** option per section you would genuinely choose,
   as this person.
3. Tap **Confirm setup**. You're done once the app confirms with "Setup
   confirmed".

Set it up the way *you* would actually use the studio — the task does not tell
you which options to pick; decide from what each option says. You do not need
to write any files; confirming the setup records it.
