# Borrow two books in Northbridge Library

The **Northbridge Library** app is already open with two temporary displays,
each containing five books. Review the available books and borrow exactly one
book from Display A and one from Display B that you would genuinely most want
to read. All books have the same four-week loan period, approximate reading
time, and are available in hardcover today.

Select a title to read its details, add one book from each display, and click
**Borrow selected books**. You are done when the app confirms the loan. The app
records the result itself; do not write any files.
