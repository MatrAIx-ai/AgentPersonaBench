# Set up your morning kit in the KitStart app

The **KitStart** health app is already open on screen, showing your setup: an
every-morning activity block and one always-on tracker widget.

1. Read the options in both sections — scroll if needed.
2. Tap **Pick** on the **one** option per section you would genuinely use, as
   this person.
3. Tap **Confirm kit**. You're done once the app confirms with "Kit confirmed".

Set it up the way *you* would actually use it — the task does not tell you
which options to pick. You do not need to write any files; confirming the kit
records it.
