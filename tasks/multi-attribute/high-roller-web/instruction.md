# Instruction

You're sorting out money moves and social situations for yourself. On the
booking page, choose **one option in each of the six sections** for the set of
picks you'd genuinely stand behind.

- Site: `/app/input/site/index.html`

- The page records your saved plan; no file to write by hand.

Use the options as written on the page. Just pick and save — no explanation.
